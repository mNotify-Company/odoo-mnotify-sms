mNotify SMS Provider for Odoo

Professional SMS Integration for Your Business Communications

🚀 Features

  • Easy integration with mNotify SMS service
  • Bulk SMS sending capabilities
  • Automatic phone number formatting
  • Test connection functionality
  • Secure API key management
  • Error handling and logging
  • Native Odoo SMS integration
  • Customizable sender ID

📋 Requirements

  • Odoo 17.0 or later
  • Active mNotify account
  • Valid mNotify API key
  • Internet connectivity

⚙️ Configuration

Step 1: Configure Your Gateway

  1. Edit the "mNotify SMS" gateway (or create a new one)
  2. Fill in these fields:
    • API Key: Get this from your mNotify dashboard
    • Sender ID: Your preferred sender name (e.g., "YourCompany")
    • Country Prefix: "+233" for Ghana (optional)
    • Test Number: Your phone number for testing (e.g., +2332********)
    • Active: Check this box to enable the gateway

Step 2: Test Your Setup

  1. Click the "Test Gateway" button
  2. Check your phone for the test SMS
  3. If you receive it, you’re ready to go!

Step 3: Enable mNotify

  1. Go to Settings → Technical → System Parameters
  2. Create a new parameter:
    • Key: sms_mnotify.use_mnotify
    • Value: True
  3. Save

✅ That’s it! All SMS from Odoo will now use your mNotify account.

🔧 Usage

Once configured, you can send SMS messages from anywhere in Odoo:

  • Customer and vendor contact forms
  • Marketing campaigns
  • Automated workflows and reminders
  • Sales and purchase processes
  • Any custom module with SMS functionality
Note: Make sure to comply with local SMS regulations and obtain proper consent before sending marketing messages.
